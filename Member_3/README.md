# Portfolio: สมาชิกคนที่ 3 นางสาวธนพร ใจศีลธรรม

แฟ้มสะสมผลงาน (Data Science, Machine Learning / Deep Learning และ Web Application Deployment) ประกอบไปด้วย 2 โปรเจกต์หลัก ได้แก่:

* **[Tuberculosis Treatment Outcome Prediction System](https://github.com/yeoauqt/TB_Clustering)** — พยากรณ์แนวโน้มผลการรักษาวัณโรคปอด โดยเปรียบเทียบโมเดล ML/DL (ANN, RF, CatBoost, XGBoost) และคัดเลือก XGBoost มาพัฒนาต่อยอดเป็น Web Application
* **[Solar Rooftop Scout](https://solarforecasting-f8c2ak6gvrbds4wztxjojr.streamlit.app)** — พัฒนา Interactive Web Dashboard ด้วย Streamlit และ Folium ร่วมกับโมเดลอนุกรมเวลา (GRU) เพื่อประเมินศักยภาพและพยากรณ์การผลิตพลังงานไฟฟ้าบนหลังคาโรงงานอุตสาหกรรม
