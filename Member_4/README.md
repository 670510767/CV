## Featured Projects

### 1. Forecasting PM2.5 in Chiang Mai Using Machine Learning & Time Series
* **Domain:** Environmental Analytics & Predictive Modeling
* **Overview:** โปรเจกต์วิเคราะห์และพยากรณ์ค่าฝุ่นละอองขนาดเล็ก (PM2.5) ในพื้นที่ 5 อำเภอของจังหวัดเชียงใหม่ ผ่านการเปรียบเทียบโมเดล ARIMA, Exponential Smoothing, Random Forest และ XGBoost ผลการทดสอบพบว่า **XGBoost** ให้ความแม่นยำสูงสุด (MAPE ต่ำสุด) จึงถูกนำมาใช้เป็นแกนหลัก และแสดงผลลัพธ์เชิงปฏิสัมพันธ์ผ่าน Dashboard 
* **Tech Stack:** `R`, `SPSS`, `XGBoost`, `Google Data Studio (Looker Studio)`
* **Live Dashboard:** [PM2.5 Forecasting on Google Data Studio](https://datastudio.google.com/reporting/c7bf9f4c-7417-4e49-bc7c-e5394777d006)

### 2. Solar Rooftop Scout: Industrial Solar Energy Assessment
* **Domain:** Deep Learning Forecasting (Time-Series) & Web Application Deployment
* **Overview:** แพลตฟอร์ม Web Dashboard สำหรับประเมินศักยภาพการผลิตไฟฟ้าจากพลังงานแสงอาทิตย์บนหลังคาโรงงานอุตสาหกรรม ขับเคลื่อนด้วยโมเดล Deep Learning สถาปัตยกรรม **GRU (Gated Recurrent Unit)** เพื่อพยากรณ์ความเข้มรังสีดวงอาทิตย์ ประมวลผลร่วมกับพิกัดภูมิศาสตร์ (Spatial Analysis) แบบ On-Demand
* **Tech Stack:** `Python`, `PyTorch / TensorFlow`, `Streamlit`, `Folium`, `Scikit-Learn`
* **Live Demo:** [Solar Rooftop Scout Application](https://solarforecasting-f8c2ak6gvrbds4wztxjojr.streamlit.app/)
