# Portfolio: สมาชิกคนที่ 4 นายรัตนธรรม เสาภา

**แฟ้มสะสมผลงาน (Data Science, Machine Learning / Deep Learning และ Dashboard Deployment)** ประกอบไปด้วย 2 โปรเจกต์หลัก ได้แก่:

- **Forecasting PM2.5 in Chiang Mai** — พยากรณ์ค่าฝุ่น PM2.5 ในพื้นที่เชียงใหม่ โดยเปรียบเทียบโมเดล (ARIMA, Exponential Smoothing, RF, XGBoost) และคัดเลือก XGBoost มานำเสนอผ่าน Interactive Dashboard บน Google Data Studio
- **Solar Rooftop Scout** — พัฒนา Interactive Web Dashboard ด้วย Streamlit และ Folium ร่วมกับโมเดลอนุกรมเวลา (GRU) เพื่อประเมินศักยภาพและพยากรณ์การผลิตพลังงานไฟฟ้าบนหลังคาโรงงานอุตสาหกรรม
